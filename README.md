# Bertahan Hidup — Godot Starter Project

Starter project Godot 4.x untuk game 2D Top Down Pixel Art, orientasi Landscape.

## Isi ZIP
- Proyek Godot yang dapat dibuka langsung dari `project.godot`.
- Struktur folder scenes, scripts, data, dan assets.
- Prototipe awal: karakter bergerak, kolam, bibit/pakan, progres pertumbuhan sederhana, panen, Farm Value, Job Level, dan save lokal.
- Asset pixel art orisinal sederhana: player, slime, ikan, kolam, tiles, dan panel UI.
- Katalog data JSON untuk ikan, item, dan monster.

## Kontrol prototipe
- WASD / tombol panah: bergerak.
- E: interaksi dengan kolam.
- Dekati kolam:
  - Jika kosong: masukkan bibit.
  - Jika ikan belum siap dan stok pakan rendah: beri pakan.
  - Jika siap panen: panen ikan.

## Menjalankan
1. Ekstrak ZIP.
2. Buka Godot 4.x.
3. Import proyek dengan memilih file `project.godot`.
4. Tekan F6/F5 atau tombol Play.

## Catatan
Ini adalah fondasi prototipe, bukan game lengkap. Data ekonomi dan waktu pertumbuhan masih berupa nilai uji awal. Prototipe saat ini memakai input keyboard; kontrol sentuh Android, seluruh wilayah, monster AI lengkap, toko, quest, breeding, crafting, dan UI final belum diimplementasikan.
Aset pixel art dalam paket ini dibuat khusus untuk proyek ini dan dapat dimodifikasi.
